# AI Agent Architecture

This note covers the fundamentals of building AI Agents.

## Introduction
An AI agent is an autonomous entity that observes its environment, makes decisions, and takes actions to achieve a specific goal.

### Key Components
- **LLM**: The brain of the agent.
- **Tools**: Actions the agent can perform.
- **Memory**: Context from past interactions.

## Workflows
1. Think
2. Act
3. Observe
